# 화면 시안

claude.ai 디자인 캔버스에서 만든 HTML 목업이다. 화면 구성과 흐름을 보기 위한 것으로, 앱 코드로 그대로 쓰지 않는다. 실제 앱은 SwiftUI로 다시 만든다.

- `mockups/canvas.json`: 캔버스 배치, 시나리오 제목, 유저 액션 메모
- `mockups/*.dc.html`: 화면별 원본 (390×844, iPhone 기준). 캔버스 런타임 전용 형식이라 브라우저로 직접 열면 일부가 다르게 보일 수 있다.
- 원본 캔버스(눌러보기 가능): https://claude.ai/artifact/3jAJiU2GNC6APbsEh15ppH

카드명과 금액은 모두 예시 값이다.

## 시나리오 1 · 결제 직전 추천과 기록

| 화면 | 파일 | 내용 |
| --- | --- | --- |
| 1-1 추천 | Main | 감지된 가맹점, 금액(선택), 1등 카드·계산 근거·남은 한도, 다른 카드 금액·불가 사유, 실적 모름 시 병기 |
| 1-2 장소 선택 | Place | 주변 후보, 검색, 업종 선택 |
| 1-3 결제 기록 확인 | Record | 금액 확인·수정, 예상 혜택, 실적·한도 변화 미리보기 |
| 1-4 기록 완료 | Recorded | 반영 결과, 되돌리기, 청구서 대조 안내 |

## 시나리오 2 · 카드 등록과 혜택 상세

| 화면 | 파일 | 내용 |
| --- | --- | --- |
| 2-1 내 카드 | Cards | 검증됨/준비 중 상태, 카드 누르면 상세 |
| 2-2 카드 추가 | AddCard | 카드사 → 신용/체크 → 지원 카드 추가 |
| 2-3 없는 카드 요청 | Request | C안 요청, 진행 과정 안내 |
| 2-4 카드 혜택 상세 | Detail | 실적 구간, 혜택별 한도 사용률, 유의사항, 데이터 기준일 |
| 2-5 지난달 실적 선택 | PrevSpend | 등록 시 실적 구간 선택(모름 포함) |

## 시나리오 3 · 실제 청구와 대조

| 화면 | 파일 | 내용 |
| --- | --- | --- |
| 3-1 이번 달 현황 | Status | 카드별 실적·한도, 청구서 대조 진입 |

## 시나리오 4 · 인터랙티브 프로토타입 (Proto.dc.html)

확정된 정책이 실제로 동작하는 눌러보기용 프로토타입. 캔버스에서 재생 버튼으로 실행한다. 카드와 혜택은 정책 시험용 **예시 데이터 7장**이다.

- 추천: 금액 미입력 예상 결과, 빠른 금액, 결제수단 칩·재계산, 동률(100원)·추천 이유·다른 선택지, 할인/캐시백/“원 상당” 표시, 마일 가치, 전용 포인트, 실적 모름 “최대”, 계산 불가, 해외 미지원
- 장소: 근처·온라인·업종 버튼·검색, 실내(후보 여러 개) 상황
- 기록: 카드·금액·결제수단 확인 → 실적·한도 반영 → 되돌리기
- 내 카드·카드 추가(실적 구간, 멤버십, 이미 받은 혜택)·요청·상세(사용액 고치기)
- 이번 달: 실적·한도 바, 기록 취소, 청구서 대조·신고, 매월 실적 확인
- 더보기: FAQ, 마일 가치, 기본 결제수단, 테스트 상황, 초기화
- `prototype/engine.js`: 계산 로직(정책 06~09 반영), `prototype/component.js`: 화면 상태 로직. 실제 앱의 규칙 엔진을 만들 때 참고용이며, 테스트 케이스 기반으로 다시 구현한다.

아직 없는 화면: 관리자 검수 화면(웹), 온보딩·권한 요청.

# 실적·한도 정책 (2단계 확정)

2026-11-08 확정. 전월 실적 입력 방식은 `04-data-strategy.md`, 등록 시점 한도 처리는 `06-recommendation-policy.md` 3번을 따른다.

## 1. 월 기준일

- 실적 집계 기간과 한도 초기화 시점은 **카드 데이터의 기준 필드**를 따른다.
- 기본값은 달력 월(1일~말일). 다른 기준을 쓰는 카드는 상품설명서대로 데이터에 넣는다.

## 2. 실적 제외 항목

- 카드마다 실적에서 빠지는 결제(예: 상품권, 공과금, 등록금, 해외 이용 등)를 카드 데이터에 제외 목록으로 둔다.
- 결제 기록 시 업종으로 자동 판단해 “실적 제외”를 표시한다.
- 사용자가 기록 화면에서 실적 포함 여부를 직접 바꿀 수 있다.

## 3. 할인받은 금액의 실적 반영

- 결제액 전체를 실적으로 보는지, 할인 후 금액만 보는지는 카드 데이터 필드로 처리한다.

## 4. 취소·환불

- 기록 목록에서 “취소됨”으로 바꾸면 해당 결제를 실적과 한도에서 뺀다.
- 부분취소는 기록 금액을 고친다.
- 지난달 결제의 취소는 해당 달 기록에서 처리한다.

## 5. 할부

- 결제 기록에 할부 여부를 남긴다.
- 실적 반영 방식은 카드 데이터 규칙을 따른다.

## 6. 값의 출처 표시

- 실적과 한도 값마다 “기록으로 추정” / “직접 확인”을 구분해 표시한다.

## 3단계 스키마 반영 사항

카드별 실적 집계 기준·한도 초기화 기준, 실적 제외 업종 목록, 할인 후 금액 실적 반영 여부, 할부 실적 반영 방식.

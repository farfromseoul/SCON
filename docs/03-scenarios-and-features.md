# 사용 시나리오, 기능 목록, 엣지케이스

작성: 2026-11-07. 기획 초기에 넓게 펼친 목록이다. MVP 포함 여부는 `01-service-overview.md`의 범위 표가 기준이다.

## 서비스 축

- **순간의 판단** (핵심): 결제 직전, 지금 이 카드가 정답인가
- **월 단위 관리** (확장): 실적·한도·정기결제 배치·연회비까지 카드 조합 최적화

## 사용자 유형

| 유형 | 특징 | 원하는 것 |
| --- | --- | --- |
| 일반 다카드 보유자 (메인) | 2~3장, 혜택 잘 모름 | “그냥 뭐 쓰면 돼?” 한 줄 답 |
| 체크카드 중심 | 사회초년생, 대학생 | 체크카드 정확한 계산, 연말정산 관점 |
| 혜택 관리형 | 4장 이상, 실적 구간 관리 | 실적·한도 추적, 몰아주기 |
| 여행·해외 결제자 | 해외 결제 빈번 | 해외수수료, 라운지, 마일리지 |
| 카드 발급 고민자 | 새 카드 탐색 | 내 소비에 맞는 카드 |

## 기능 영역

1. **카드 등록/관리**: 카드사→상품 선택(카드번호 없음), 별명·색상, (후순위) 카드 사진으로 상품 매칭
2. **혜택 조회**: 카드별·업종별 조회, 조건을 쉬운 말로 번역
3. **추천 엔진**: 가맹점 + 금액 + 내 상태 → 카드별 예상 혜택, 이유·불가 사유. 모드: 이번 결제 최대 / 이번 달 최대(몰아주기 고려)
4. **위치/가맹점 식별**: GPS 후보 + 사용자 확인, 즐겨찾는 장소, 지오펜스(후순위)
5. **실적·한도 관리**: 원탭 기록, (2차) 단축어로 결제 문자 기록, (후순위) 마이데이터, 실적 제외 항목 처리
6. **알림**: 도착, 월말 실적, 한도 소진, 혜택 개편, 실적 구간 하락, 청구서 대조, 매월 1일 실적 확인
7. **리포트**: 받은/놓친 혜택, 연회비 가치, 업종별 지출
8. **카드 추천(발급)**: 보완 카드, 수익모델 후보(규제 검토 필요)

## 엣지케이스 (정책서에서 하나씩 처리 방법을 정한다)

- 실적 산정 제외: 상품권, 세금, 공과금, 할부 수수료, 이미 할인받은 금액
- 결제 취소·부분취소 시 실적·한도 차감
- 같은 카드의 혜택 중복 불가
- 가맹점 오분류: 몰 안 매장, 직영 vs 가맹, 카드사별 업종 분류 차이
- 간편결제 경유 시 업종 변경 (예: 스타벅스 결제가 “네이버페이”로 찍힘)
- 금액 미입력 시 정률·정액 비교 방법
- 동률 처리: 실적 몰아주기 우선 vs 포인트 가치 우선
- 포인트·마일리지 환산 가치
- 카드 교체·재발급·단종 시 혜택 유지 구간
- 월 기준일 (1일 기준 vs 결제일 기준, 카드마다 다름)
- 데이터 신선도 표시, 오류 제보
- 선택형 카드의 월별 모드

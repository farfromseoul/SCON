# 경쟁·유사 서비스 분석

조사일: 2026-11-07. 앱 기능은 공개된 앱스토어 설명·릴리즈 노트와 기획자의 직접 사용 경험 기준.

## 유형별 정리

| 유형 | 서비스 | 핵심 질문 | 우리와의 관계 |
| --- | --- | --- | --- |
| 카드 정보·비교 플랫폼 | 카드고릴라 | 어떤 카드를 발급할까? | 혜택 분류 체계·인기 순위 참고 |
| 커뮤니티 | 스사사 (네이버 카페) | 이 카드 실제로 어떻게 써? | 엣지케이스·사용자 불편 수집처 |
| 마이데이터 자산관리 | 뱅크샐러드, 토스 | 내 소비에 맞는 새 카드는? | 발급 중개가 수익원이라 “보유 카드 중 선택”엔 동기 약함 |
| 결제 순간 추천 (국내) | 카드피커, 플레이플래닛, (과거) 추카 | 지금 어떤 카드? | 직접 경쟁 |
| 결제 순간 추천 (해외) | CardPointers, MaxRewards | 지금 어떤 카드? | UX·기능 벤치마크 |

## 서비스별 메모

### 카드고릴라
- 고릴라차트: 카드 페이지 조회수 + 신청 전환수로 순위.
- 혜택 필터: 약 23개 대분류, 100여 개 상세 혜택 → 우리 업종 분류의 출발점으로 벤치마크.
- 2026년 상반기 인기 1위가 신용·체크 모두 “선택형 혜택” 카드. 하나카드는 매달 모드를 바꾸는 카드 출시 → 선택형 카드의 “이번 달 모드” 입력이 필수 기능.
- 타사 DB는 복제하지 않는다(데이터베이스 권리 침해 소지). 우선순위 참고용으로만.

### 스사사
- 카드·마일리지·상테크 고급 활용 커뮤니티. 서비스가 아니라 고급 사용자층과 엣지케이스가 모이는 곳.
- 상테크는 티몬·위메프 사태 이후 축소, 무실적 카드 관심 증가.

### 뱅크샐러드 / 토스
- 뱅크샐러드 초기: 결제 문자 인식 → 이번 달 할인·적립 분석, 다른 카드였으면 얼마 더 받았을지, 소득공제 계산. 마이데이터 없이 구현 가능한 검증된 기능 조합.
- 현재: 마이데이터 기반, 카드 발급 중개 수수료가 주 수익. 마이데이터 라이센스 자체가 진입장벽.

### 카드피커 (직접 경쟁)
- 카드사→상품명 선택 등록, 업종·금액 입력 → 순위. 발급 카드 1,188장. 로그인 없이 하루 3회.
- 최근 업데이트: “이 카드로 결제했어요” 원탭 기록(실적·한도 반영, 되돌리기), 등록 시 지난달 실적 선택, 혜택 옵션(국내형/해외형) 설정, 혜택 오류 신고, 통합한도 집계 개선.
- 약점: 공식 자료가 없는 카드는 AI 추정, “실제 혜택과 다를 수 있음” 고지. **기획자가 직접 써보니 체크카드 등록 시 “정보가 제공되지 않는 카드”로 나옴.**
- 설명상 위치 자동 감지·위젯·잠금화면 없음.

### 플레이플래닛
- 지도에서 주변 매장 할인율, 매장 자체 할인 + 내 카드 혜택 합산. “어디서 쓸까” 중심. 매장 할인 합산은 v2 참고.

### 추카 (2015, 브릴리언츠)
- 위치 기반으로 내 카드 중 최대 할인 카드 추천, 자주 가는 가맹점 등록. 현재 찾기 어려움.
- 교훈: 아이디어는 새롭지 않다. 데이터 유지 비용과 수익모델이 지속 여부를 가른다.

### CardPointers (미국)
- “넓은 카드 DB + 빠른 UX”. 은행 로그인 없이 DB에서 카드 추가.
- AutoPilot: 위치로 매장별 최적 카드, Live Activity, 워치·CarPlay, 위치는 기기 밖으로 안 나감.
- Siri “CardPointers here”, 제어센터·잠금화면 컨트롤, 위젯, Spotlight·단축어, 브라우저 확장.
- 유료 월 7.5달러/연 90달러. 한국 앱스토어에서 설치 가능하나 영어, 미국 카드만 → UX 체험용.

### MaxRewards (미국)
- “계정 연동 + 자동화”. 카드 계정 읽기 전용 연동, 오퍼·보너스 카테고리 자동 활성화, 혜택 자동 추적.
- 카드 3장 이상 사용자에게 적합. 한국에선 마이데이터 필요 → 원탭 기록·단축어로 대체.
- 미국의 “오퍼 자동 활성화”에 해당하는 한국 기능 = 응모가 필요한 카드사 이벤트 알림.

## 결론: 우리가 파고들 자리

한국형 카드 구조(전월실적 구간, 통합 한도, 선택형 혜택)를 검수된 데이터로 정확히 계산하면서, CardPointers처럼 앱을 열지 않고도 빠르게 답을 주는 앱. 체크카드 완성도가 첫 차별점.

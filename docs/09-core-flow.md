# 핵심 플로우 (2단계 확정)

2026-11-08 확정. 화면 구성은 `design/README.md`의 시안을 기준으로 한다.

## 결제 직전 추천 (시나리오 1)

1. **앱 열기 → 가맹점 자동 선택**: 가장 가까운 가맹점을 자동으로 고르고 “장소 변경”을 둔다.
   - 신뢰도가 낮을 때(실내, 가까운 후보가 여러 개)는 자동 선택 대신 후보 목록을 먼저 띄운다.
   - 위치를 못 잡거나 권한이 없으면 검색·업종 버튼 화면으로 간다.
   - 온라인 가맹점(쿠팡, 배달앱 등)은 검색·업종 버튼으로 고른다.
2. **금액(선택)**: 입력하지 않으면 업종 대표 금액 기준 예상 결과. 빠른 선택 5천 / 1만 / 3만.
3. **결제수단 칩**: 기본 결제수단으로 계산, 바꾸면 재계산.
4. **결과**: 1등 카드를 크게(혜택, 계산식, 남은 한도), 나머지 카드는 금액과 불가 사유. 동률이면 이유와 다른 선택지 표시.
5. **결제 기록(원탭)**: 금액·결제수단 확인(미리 채움, 수정 가능) → 기록 → 실적·한도 반영, 되돌리기 가능.

## 카드 등록 (시나리오 2)

카드사 선택 → 신용/체크 → 지원 카드 선택 → 지난달 실적 구간 → (해당 카드면) 멤버십 등 조건 질문 → (선택) 이번 달 이미 받은 혜택 → 등록. 목록에 없으면 요청 대기열(C안).

## 청구서 대조 (시나리오 3)

청구 알림 → 건별 맞아요/달라요 → 달라요는 실제 금액·사유와 함께 신고. 매월 1일 지난달 실적 구간 확인.

# 예외 처리 정책 (2단계 확정)

2026-11-08 확정.

| 상황 | 처리 |
| --- | --- |
| 혜택 데이터가 없는 카드 (검수 전) | “계산 불가”로 표시하고 순위에서 뺀다 |
| 혜택 대상인지 불확실한 가맹점 | 1등 계산은 확실한 혜택만으로 한다. 불확실한 혜택은 “적용될 수 있음 +600원”처럼 따로 표시한다 |
| 선택형 카드의 이번 달 모드 미설정 | “계산 불가” + 모드 설정 유도 |
| 전월 실적 모름 | 충족 시 / 미달 시 혜택 병기 (`04-data-strategy.md`) |
| 해외 결제 | MVP에선 계산하지 않고 안내만 표시 |
| 가족카드 | 별도 카드로 등록은 허용. 본인 카드와의 실적 합산은 v2 |
| 카드 혜택 변경·단종 | 데이터에 버전을 두고, 변경일 이전 기록은 이전 규칙으로 계산. 보유 카드가 바뀌면 알림 |
| 카드 상품 변경 (교체) | 새 카드로 등록. 이전 카드 기록은 이관하지 않는다 |
| 위치 권한 거부 | 검색과 업종 버튼으로 그대로 사용 |
| 인터넷 연결 없음 | 데이터가 기기 안에 있어 계산은 된다. 주변 가맹점 찾기만 안 된다 |

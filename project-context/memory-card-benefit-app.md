# 프로젝트 메모리 (Claude 메모리에 기록된 내용, 2026-11-08 기준)

기획자가 대화에서 직접 말한 사실만 모은 것이다.

- 보유한 체크/신용카드를 등록해 카드별 혜택을 확인하고, 현재 소비 장소에서 가장 큰 혜택의 카드를 추천하는 앱을 만들려고 함
- 진행 순서: 아이디어·시나리오·기능 기획을 먼저 꼼꼼히 한 뒤, 디자인과 설계는 구체화 이후 진행
- 카드고릴라, 스사사 등 기존 서비스 정보를 참고하려고 함
- 컨셉 결정: 카드피커, CardPointers, MaxRewards의 장점을 가져온 앱
- MVP로 진행해 TestFlight까지 배포하고 본인이 직접 사용해볼 계획 (기획을 충분히 논의한 뒤 진행)
- 정확도 최우선: 신용·체크 인기 상위 300장을 최종 목표로 하되 초기에는 20장 정도로 작게 시작, 신용·체크 둘 다 지원 (본인도 체크카드를 많이 씀)
- 카드 등록은 지원 목록 선택 + 미지원 카드는 요청 대기열에 올려 검수 후 게시하는 방식(C안), 관리자가 카드 정보를 조회·관리하는 구조 필요
- AI는 혜택 추출 단계에서만 쓰고 추천 계산은 규칙 엔진으로
- 개발 전 모든 단계에 직접 개입하며, 단계별 산출물을 만들고 확정한 뒤 천천히 다음 단계로 넘어감
- 전월 실적: 등록 시 구간 선택, 모르면 병기, 매월 확인으로 진행
- 카드 데이터: 수집 → AI 추출 → 검수 → 게시 흐름
- 처음엔 무료로 본인 기기에서 사용해보고, 이후 Apple Developer Program 가입 예정
- 코딩·앱 개발은 이 저장소를 Claude Code에 연결해 진행
